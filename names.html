名前の一覧の登録

名前の一覧をパスワードで暗号化して names.js を作ります。入力した名前とパスワードはこのブラウザの中だけで使い、どこにも送りません。

1. 名前の一覧を読み込む

「出席番号, 名前, ふりがな」の CSV ファイルを選ぶか、下の欄に貼り付けます。1行目が見出しでもかまいません。スプレッドシートから3列をコピーして貼り付けることもできます。

番号名前ふりがな

2. パスワードを決める

座席表を出力するときに入力します。名前を守るのはこのパスワードだけなので、8文字以上の、推測されにくいものにしてください。

3. GitHub に置く

  1. GitHub でこのリポジトリの names.js を開き、鉛筆のアイコン（Edit）を押します。
  2. 中身をすべて消して、上の内容を貼り付けます。
  3. 「Commit changes」を押します。数分で公開ページに反映されます。
