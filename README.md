# 席替えシステム

ボタン1つで、出席番号 1〜42 の全員を座席にランダムに配置します。GitHub Pages でそのまま公開できます（ビルド不要）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `config.js` | **設定（座席の配置・出席番号・名前・前希望）** |
| `seating.js` | 席替えのロジック |
| `test/seating.test.js` | ロジックのテスト（`node --test test/*.test.js`） |
| `tools/build_artifact.py` | Claude のアーティファクト（プレビュー）用に1ファイルにまとめるスクリプト |

## 設定の変え方（`config.js`）

- **前希望**：その番号の `front: false` を `true` にします。
  前希望の人は前から `frontRows`（3）列目までのどこかにランダムで入ります。入りきらないときだけ、4列目、5列目…の順に入ります。
- **名前**：`name: ""` に名前を入れると、番号の下に表示され、書き出しにも入ります。
- **座席の配置**：`layout` の `S` が座席、`.` が座席なしです。1行目が教室の前（黒板側）です。

## 書き出し

- **PDF・印刷**：ブラウザの印刷画面が開きます。送信先を「PDFに保存」にすると PDF になります（A4縦1枚）。
- **CSVで保存**：座席表と、出席番号順の一覧（前から何列目・左から何番目）を CSV で保存します。Google スプレッドシートの「ファイル → インポート」で開けます。
- **表をコピー**：座席表をコピーします。Google スプレッドシートに貼り付けるとそのまま表になります。

「教卓から見る」を押すと、教卓側から見た向き（上下左右が逆、黒板が下）に切り替わります。印刷・書き出しも画面と同じ向きになります。

直前の席替え結果はブラウザに保存されるので、ページを再読み込みしても消えません。

## GitHub Pages での公開

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`（フォルダは `/ (root)`）にします。
