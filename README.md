# 席替えシステム

ボタン1つで、出席番号 1〜42 の全員を座席にランダムに配置します。GitHub Pages でそのまま公開できます（ビルド不要）。

## 使い方

| ボタン | すること |
| --- | --- |
| 席替えする | 全員をランダムに配置します |
| 1つ前に戻す | 直前の配置に戻します |
| 教卓から見る | 教卓側から見た向き（上下左右が逆、黒板が下）に切り替えます。出力も画面と同じ向きになります |
| 前希望 | 番号を押して前希望の人を選びます。選んだ人は前から3列目までに入ります。入りきらないときだけ、4列目、5列目…の順に入ります |
| 座席表を出力 | PDF（印刷）・Excel・コピーで座席表を出力します。名前を入れるときはここでパスワードを入力します |

- 画面には番号だけを表示します。名前は出力するときだけ使います。
- 席替えの結果・向き・前希望・パスワードはその端末のブラウザに保存されます。再読み込みしても消えません。
- 出力する座席表は A4 横1枚です。上にタイトル（「3年6組座席表」）・日付（「○月○日～」）・教卓・在籍人数が入り、各席の四角の左上に出席番号、中に名前が入ります。日付は出力画面で変えられ、「日付を入れる」を外すと入りません。
- 「PDF・印刷」ではブラウザの印刷画面が開きます。送信先を「PDFに保存」にすると PDF になります。印刷画面では用紙を A4・横向きにしてください。座席表は用紙の余白や倍率に合わせて縮むので、1枚からはみ出しません。
- Excel ファイルには、印刷と同じ見た目の「座席表」と、「一覧」（出席番号順、前から何列目・左から何番目）の2つのシートが入っています。Google スプレッドシートでも開けます。
- 「表をコピー」で座席表をコピーし、スプレッドシートに貼り付けることもできます。

## 名前の登録

名前はパスワードで暗号化して `names.js` に入れます。リポジトリを見られても、パスワードがなければ名前は読めません。

1. 公開ページの `names.html`（座席表を出力 → 「名前の一覧を登録する」）を開きます。
2. 名前を出席番号順に1行ずつ入力し、パスワードを決めて「names.js を作る」を押します。
3. 出てきた内容で、リポジトリの `names.js` の中身を置き換えます。

名前やパスワードを変えるときも、同じ手順で作り直します。

## 設定（`config.js`）

- **前希望の初期値**：その番号の `front: false` を `true` にします。画面の「前希望」で変えた内容は、その端末ではそちらが優先されます。
- **座席の配置**：`layout` の `S` が座席、`.` が座席なしです。1行目が教室の前（黒板側）です。
- **クラス名**：`className`（座席表のタイトルになります）。
- **前希望を入れる範囲**：`frontRows`（前から何列目まで）。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 席替えの画面 |
| `names.html` | 名前の一覧を暗号化して `names.js` を作る画面 |
| `config.js` | 設定（座席の配置・出席番号・前希望の初期値） |
| `names.js` | 暗号化された名前の一覧 |
| `seating.js` | 席替えのロジック |
| `secret.js` | 名前の暗号化・復号 |
| `xlsx.js` | Excel ファイルの書き出し |
| `test/seating.test.js` | テスト（`node --test test/*.test.js`） |
| `tools/build_artifact.py` | Claude のアーティファクト（プレビュー）用のファイルを作るスクリプト |

## GitHub Pages での公開

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`（フォルダは `/ (root)`）にします。
